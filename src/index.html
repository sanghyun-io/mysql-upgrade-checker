서버에서 실행

                            
MySQL 서버에서 쿼리를 실행하고 결과 파일을 저장합니다.


                            
                            

                                
                                
                            


                            
                            

                                
DB 서버에 직접 접근 가능한 경우

                                

                                    

                                        mysql -h your-db-host -u admin -p < mysql84_server_check.sql > result.txt
                                        
                                    

                                    i
                                        

                                            
mysql 명령어 옵션

                                            

                                                -h
                                                MySQL 서버 호스트 주소 (예: localhost, 192.168.1.100)
                                            

                                            

                                                -u
                                                접속할 사용자 이름
                                            

                                            

                                                -p
                                                비밀번호 입력 프롬프트 표시
                                            

                                            

                                                < file.sql
                                                실행할 SQL 파일 (입력 리다이렉션)
                                            

                                            

                                                > result.txt
                                                결과를 저장할 파일 (출력 리다이렉션)
                                            

                                        

                                    
                                

                            


                            
                            

                                
AWS RDS 등 Bastion 서버를 통해 접근하는 경우


                                

                                    💡
                                    
                                        db-connector로 터널링하면 "로컬 연결" 방식으로 바로 사용할 수 있습니다.
                                        다운로드 →
                                    
                                


                                

                                    2-1
                                    Bastion에 SQL 파일 업로드
                                

                                

                                    

                                        scp mysql84_server_check.sql user@bastion-host:~/
                                        
                                    

                                    i
                                        

                                            
scp 명령어 (파일 업로드)

                                            

                                                scp
                                                Secure Copy - SSH를 통한 파일 전송
                                            

                                            

                                                file.sql
                                                전송할 로컬 파일 경로
                                            

                                            

                                                user@host
                                                원격 서버의 사용자@호스트
                                            

                                            

                                                :~/
                                                원격 서버의 홈 디렉토리에 저장
                                            

                                        

                                    
                                


                                

                                    2-2
                                    Bastion에서 RDS 접속 및 실행
                                

                                

                                    

                                        ssh user@bastion-host
                                        
                                    

                                    i
                                        

                                            
ssh 명령어

                                            

                                                ssh
                                                Secure Shell - 원격 서버 접속
                                            

                                            

                                                user@host
                                                접속할 사용자@호스트 주소
                                            

                                        

                                    
                                

                                

                                    

                                        mysql -h rds-endpoint.amazonaws.com -u admin -p < mysql84_server_check.sql > result.txt
                                        
                                    

                                    i
                                        

                                            
mysql 명령어 옵션

                                            

                                                -h
                                                RDS 엔드포인트 주소
                                            

                                            

                                                -u
                                                RDS 마스터 사용자 이름
                                            

                                            

                                                -p
                                                비밀번호 입력 프롬프트 표시
                                            

                                            

                                                < file.sql
                                                실행할 SQL 파일
                                            

                                            

                                                > result.txt
                                                결과 저장 파일
                                            

                                        

                                    
                                


                                

                                    2-3
                                    결과 파일 로컬로 다운로드
                                

                                

                                    

                                        scp user@bastion-host:~/result.txt ./
                                        
                                    

                                    i
                                        

                                            
scp 명령어 (파일 다운로드)

                                            

                                                scp
                                                Secure Copy - SSH를 통한 파일 전송
                                            

                                            

                                                user@host:
                                                원격 서버의 사용자@호스트
                                            

                                            

                                                ~/result.txt
                                                다운로드할 원격 파일 경로
                                            

                                            

                                                ./
                                                현재 디렉토리에 저장
